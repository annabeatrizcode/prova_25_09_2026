# prova_25_09_2026# Primeiros Socorros

## Sobre o projeto

Este projeto foi desenvolvido em **HTML5** com a intenção de apresentar informações sobre **primeiros socorros, situações de emergência e prevenção de acidentes** de forma simples e organizada.

## O que foi utilizado

Foram utilizados recursos do HTML5, como:

- Tags semânticas
- Listas
- Tabelas
- Formulários
- Imagens
- Áudios
- Vídeos
- Links
- `abbr`
- `mark`
- `del`
- `ins`
- `blockquote`
- `cite`
- `progress`
- `meter`
- `time`
- `details` e `summary`

## Páginas

- **Início**
- **Checklist**
- **Emergências**
- **Prevenção**

## Intenção do site

O objetivo é **informar e conscientizar** sobre cuidados básicos, prevenção de acidentes e atitudes importantes em situações de emergência.
